# Research Discovery Skill

This skill governs the identification, preservation, cataloging, and implementation of cutting-edge algorithms and architectures described in research papers.

## Workflow

### 1. Discover & Catalog
- Store all research papers and algorithm specs in the `C:\Users\ISHAAN SEN\.gemini\antigravity-ide\scratch\discovered_research\` directory.
- Maintain a clear naming convention for the files (e.g. `entropic_manifold_braiding_rag.md`).
- Create a `RESEARCH_INDEX.md` inside that folder to list and summarize all discovered papers.

### 2. Formulate Mathematical Specs
- When implementing a paper, extract the core formulas and algorithm definitions (e.g., CTFC path integrals, QSTH tensor blocks).
- Document how they replace standard baseline approaches (e.g., replacing Cosine Similarity with CTFC).

### 3. Implementation Patterns
- Build clean, modular code components implementing the algorithms.
- Support local fallback modes or standard configurations where specialized hardware is unavailable.
- Provide seed/ingestion scripts to leverage the new indexing or RAG topologies.

### 4. Continuous Discovery Rule
- Before starting any project, check the `discovered_research/` folder for relevant techniques.
- Review recent papers to verify if a more optimal, non-Euclidean, or memory-compressed method exists.
