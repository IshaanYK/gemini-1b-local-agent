# Contributing to 1B Gemini Local Agent

Thank you for your interest in contributing to **1B Gemini Local Agent**! We welcome all contributions, ideas, bug fixes, and UI improvements.

## How to Contribute

1. **Fork the repo** on GitHub.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/1B-gemini-Local-Agent-.git
   cd 1B-gemini-Local-Agent-
   ```
3. **Create a branch** for your work:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes** and test them locally using `Launch_Gemini_Agent.bat`.
5. **Commit your changes**:
   ```bash
   git commit -m "feat: describe your change cleanly"
   ```
6. **Push to GitHub**:
   ```bash
   git push origin feature/your-feature-name
   ```
7. **Submit a Pull Request**!

## Guidelines
- Keep code clean and well-commented.
- Preserve the Apple HIG design language for frontend changes.
- Ensure the agent's 6 native tools remain backward-compatible.
- Please give the repository a ⭐ **Star** if you haven't already!
